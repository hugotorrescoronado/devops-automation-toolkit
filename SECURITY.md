# Security Policy

## Supported Versions

The latest version of this repository is actively maintained.

## Reporting a Vulnerability

If a vulnerability is identified:

1. Do not publish the issue publicly.
2. Report the issue through GitHub Security Advisories.
3. Provide reproduction steps when possible.

## Security Controls

This repository includes:

- GitHub Actions Validation
- Gitleaks Secret Scanning
- Bandit Python Security Analysis
- Dependabot Dependency Monitoring
- Dependency Review
